# ⚙️ Imóvel - Backend

API do sistema de gestão de imóveis.

## 🛠️ Tecnologias

- Python
- FastAPI / Flask
- MySQL / PostgreSQL

## 🚀 Como rodar localmente

```bash
# Instalar dependências
pip install -r requirements.txt

# Rodar o servidor
python main.py
```

## 📁 Estrutura

```
backend/
├── main.py        # Arquivo principal
└── database.sql   # Estrutura do banco de dados
```
